# 策略回测

策略回测由回测配置、策略参数、两阶段查询以及 DolphinDB 回调组成。运行成功后，网页在浏览器内计算指标并展示净值、回撤、持仓和交易明细。

## 配置回测

进入[策略回测](/backtest)并新建策略。左侧普通参数包括：

- 复权方式、初始资金、年化交易日、无风险利率；
- 手续费率、印花税率和最低手续费开关；
- 动态或静态股票池；
- 策略参数，多行输入且每行使用 `key=value`。

策略参数支持数值、布尔值、`null` 和字符串。回调代码可通过 `getParams()` 读取提交的参数字典。

## 编辑策略代码

“策略代码”区域按职责打开独立编辑面板：

1. **股票池查询：** 仅动态股票池显示。第一阶段查询整个区间可能使用的代码集合。
2. **回测数据查询：** 第二阶段查询回测实际需要的字段、派生数据和逐日成员标记。
3. **工具函数：** 插入到回调之前，可声明函数或全局代码；其中定义的函数会进入回调编辑器提示。
4. **回调函数：** 编辑 initialize、beforeTrading、onSnapshot、onOrder、onTrade、afterTrading、finalize 等生命周期函数。

编辑器支持 DolphinDB 官方语法高亮、函数文档、自动补全、代码折叠、缩进参考线、Minimap 和格式化。格式化只调整排版，不改写策略语义。

静态股票池必须实际选择代码；动态股票池必须保留股票池查询。执行前页面会统一校验策略参数、查询 DSL 和回调内容。

## 执行并阅读报告

点击“执行回测”后，右侧直接显示运行日志。成功后报告提供：

- **回测概览：** 累计/年化收益、Sharpe、波动率、费用、净值、总资产、滚动 Sharpe、回撤和分年度/月份表现；
- **交易记录：** 委托和成交状态事件；
- **每日持仓：** 每日证券持仓明细；
- **组合资产：** 现金、市值、总权益和净值；
- **交易统计：** 仅在当前 DolphinDB Backtest 插件支持对应接口并实际生成文件时可用。

顶部日期范围条会同时改变概览指标、图表和各数据表。表格支持列筛选、分页及完整 Excel 导出。

## 版本、队列与专项分析

回测项目与因子项目使用相同的草稿和版本流程：成功后保存版本，历史版本只读，可基于历史版本继续回测或进行版本/项目对比。

三个点菜单包含执行队列，以及仅对已保存版本开放的专项分析：

- **手续费分析：** 批量测试一组手续费率并比较策略指标变化；
- **参数敏感性：** 从策略参数中选择一个或两个简单参数，构造参数网格并查看折线图或热力图；
- **参数调优：** 选择数值型策略参数、候选值和调优算法，设置滚动回看/持有区间、重复次数与评估预算，比较样本外净值路径。

每个版本可以保留多份专项分析记录。运行期间关闭弹窗不会终止任务，再次打开可以从历史列表继续查看状态和报告。

## 先确认执行契约

网页说明解决“按钮怎么用”，不替代撮合和数据语义。复权尺度、合成快照、订单状态、回调字段、动态指数成员与防未来数据等内容会直接影响结果；正式研究前请阅读 [MCP Backtest 文档](/mcp?doc=backtest/dolphindb)中的当前运行契约。
