# 快速开始

Arena 把数据查询、因子分析和策略回测组织成可追踪的后台任务。你可以关闭详情页或刷新浏览器；任务仍在 DolphinScheduler 中执行，重新打开项目后页面会继续读取状态和结果。

> 最短路径：选择应用 → 新建项目 → 填写左侧参数 → 执行 → 查看右侧日志 → 等待结果 → 因子或回测项目保存版本。

## 完成一次研究

| 步骤 | 在网页中的操作 | 页面会发生什么 |
| --- | --- | --- |
| 1 | 从顶部导航进入数据查询、因子分析或策略回测 | 进入对应项目列表 |
| 2 | 点击“新建查询”“新建分析”或“新建策略” | 创建项目并进入详情页 |
| 3 | 在左侧填写日期、股票池、参数与 DSL | 编辑器即时校验结构并提供代码提示 |
| 4 | 点击执行按钮 | 创建后台工作流，右侧立即切换为运行日志 |
| 5 | 等待状态变为成功 | 页面自动读取 Parquet，并在浏览器中生成表格或报告 |
| 6 | 因子分析和策略回测点击“保存” | 当前未保存版本固定下来，同时生成下一个可编辑草稿 |

## 详情页的共同布局

- **左侧是输入。** 项目参数、DSL、策略代码、执行与保存操作都在这里。
- **右侧是过程和结果。** 执行期间直接显示日志；完成后切换为查询表格、因子报告或回测报告。
- **执行按钮会变成终止按钮。** 只有仍在运行的工作流可以终止。
- **三个点是辅助操作。** 展示完整 JSON、Task 日志、执行队列以及针对已保存版本的研究工具都在这个菜单中。
- **页面刷新不会取消任务。** 当前工作流 ID 与状态保存在后端，详情页会恢复轮询。

## 三类项目的区别

| 应用 | 保存什么 | 是否有版本 | 适合解决的问题 |
| --- | --- | --- | --- |
| 数据查询 | 当前一次查询的 Parquet | 否 | 准备数据、验证 DSL、生成后续股票池或 SQL 数据源 |
| 因子分析 | 因子参数、结果与摘要 | 是 | 研究 IC、RankIC、分组收益和衰减 |
| 策略回测 | 策略参数、代码、交易与净值结果 | 是 | 验证策略表现并进行费用、敏感性和调优分析 |

## 建议的使用顺序

1. 先在[数据查询](/query)中确认股票代码、字段和派生逻辑。
2. 再在[因子分析](/factor)中验证信号的统计性质。
3. 最后在[策略回测](/backtest)中编写回调并检查实际订单、持仓和资产曲线。
4. 运行异常时进入[工作流](/workflows)，按 Workspace 展开 Attempt 与 Task，读取完整日志。

MCP 是同一套能力的 Agent/API 入口。网页操作请继续阅读本使用文档；请求字段和执行契约请前往 [MCP](/mcp)。
