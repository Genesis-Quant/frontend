# 数据查询

数据查询用于编写 Dataset Query DSL、生成 Parquet，并把结果作为因子分析、策略回测或浏览器 SQL 的数据来源。每个用户最多创建 5 个查询项目。

## 创建并执行查询

1. 进入[数据查询](/query)，点击“新建查询”并填写项目名称。
2. 在详情页设置开始日期、结束日期和回溯周期。
3. 股票代码可以直接输入，也可以从已有成功查询结果的 `code` 列去重后选取。
4. 在 DSL 编辑器中填写 `factors`、`derivatives` 与 `filters`。编辑器会校验 JSON，并根据 Catalog 提供字段、操作符和函数提示。
5. 点击“执行查询”。工作流运行时，右侧直接显示 Task 日志；成功后自动显示查询结果。

查询项目不创建历史版本。再次执行会保留 Attempt 历史，但项目当前结果会切换到最新一次成功运行。

## 查看和筛选结果

查询完成后，Parquet 在浏览器中由 DuckDB 读取。结果区支持：

- 拖动“结果区间”选择日期，滑块始终显示当前日期；
- 对每列添加筛选条件、切换排序和选择分页大小；
- 数值列按当前列数值范围显示由蓝到红的背景色；
- 点击下载按钮导出全部原始数据为 Excel，而不是只导出当前页；
- 刷新页面后重新加载当前工作流绑定的 Parquet。

三个点菜单中的“展示参数”会打开完整 JSON 请求体。你可以直接编辑并应用 JSON；“Task 日志”用于查看所有节点及分页日志。

## SQL 二次查询

在查询项目列表点击“SQL 二次查询”：

1. 选择一个或多个状态为成功的查询项目作为数据源。
2. 每个项目注册为 `query_<项目ID>`，例如项目 12 对应 `query_12`。
3. 在 SQL 编辑器中编写 DuckDB SQL，可跨多个 Parquet 进行关联、聚合和窗口计算。
4. 点击“执行 SQL”，结果仅在当前浏览器会话展示，不创建项目、工作流或版本。

```sql
SELECT a.time, a.code, a.close, b.industry
FROM query_12 AS a
LEFT JOIN query_18 AS b USING (time, code)
ORDER BY a.time, a.code;
```

SQL 二次查询直接读取已经生成的 Parquet，不会重新执行原始 Dataset Query。

## 常见问题

- **执行按钮不可用：** 先修复 DSL 编辑器标出的结构错误。
- **结果为空：** 表格操作栏仍会保留，可清除日期或列筛选后重试。
- **SQL 没有数据源：** 只有当前用户状态为成功且仍有可用结果的查询项目会出现在列表中。
- **需要历史请求：** 到工作流页展开该 Workspace，打开对应 Attempt 详情；项目页只表示当前结果。
