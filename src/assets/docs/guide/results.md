# 结果、导出与排错

Arena 的后台任务生成 Parquet，网页拿到结果地址后在浏览器中使用 DuckDB WASM 进行二次查询、日期过滤、指标计算和图表生成。大部分结果浏览不会把整张表转换成后端 JSON。

## 结果在浏览器中如何工作

1. 后端确认工作流成功并校验必需输出存在、非空且具有完整 Parquet 文件尾。
2. 网页获取结果文件地址并交给 DuckDB WASM。
3. 日期范围、分页、列筛选和报告指标在浏览器中按需查询。
4. 下载 Excel 时读取完整原始结果，不受当前表格页码限制。

首次打开页面需要加载并缓存 DuckDB WASM；后续访问应复用浏览器缓存。切换版本或结果表时会注册相应 Parquet，但不会重新执行原始任务。

## 表格操作

- 表头操作区始终保留，即使当前筛选结果为零行；
- 日期列显示为格式化后的日期/时间，而不是原始时间戳；
- 数值列由小到大显示蓝色到红色的渐变背景；
- 固定列使用实色背景，横向滚动时不会与后方单元格重叠；
- 分页器支持上一页、页码、下一页、每页条数和跳页；
- 下载按钮导出全部原始数据。

## 日期范围

查询、因子和回测报告都使用同一日期范围条。拖动过程中浮层会持续显示鼠标所在日期，两个 Handle 始终显示当前起止日期。

- 查询页：范围作用于结果表格；
- 因子页：范围作用于当前因子的 IC、收益、分组与衰减区域；
- 回测页：范围作用于所有报告标签、指标、图表和明细表。

点击重置可以恢复结果文件的完整日期范围。

## 常见故障处理

### 页面一直显示运行中

先打开工作流页确认实际状态。页面刷新后仍会恢复轮询；如果状态是 `RESULT_PENDING`，说明调度已经结束但输出仍在校验，应等待后端重试。

### 结果读取失败

1. 在三个点菜单打开 Task 日志，确认任务确实上传了预期输出。
2. 在工作流详情查看状态是 `FAILURE` 还是 `RESULT_FAILED`。
3. 如果错误明确指出某个 Parquet 缺少 magic bytes 或字段不存在，不要只刷新页面，应修复产出逻辑后重新执行。
4. 如果日志显示 `getDailyTradingStatistics` 不存在或调用失败，说明运行节点插件不满足当前回测契约；
   任务会直接失败，需要统一升级插件后重新执行。

### 无法连接 Arena 服务

- 确认当前登录会话仍有效；退出后重新登录可刷新 Token。
- 本地开发检查前端 `/api` 代理是否指向正在运行的 backend。
- Build 版本检查 API 地址是否为部署环境的 HTTPS 地址，避免浏览器拦截混合内容。
- 网络恢复后直接重试读取；不要因为一次对象存储超时就重新提交任务。

### 指标和原始表对不上

先统一日期范围、年化交易日和无风险利率，再核对使用的结果表。网页报告指标由浏览器根据 `daily_portfolios` 等结果计算；订单审计应查看交易记录，持仓审计应查看每日持仓，不要用名称相近但粒度不同的列相互替代。
