# 因子分析

因子分析把股票池、数据查询和分析设置组成一次后台任务，完成后在浏览器内读取 IC 与分组收益 Parquet，生成因子报告。

## 配置分析

1. 进入[因子分析](/factor)，点击“新建分析”。
2. 选择股票池、价格字段和市值字段，并设置分组数量、最大滞后阶数、回溯周期及日期范围。
3. 在 Factor Query DSL 中编写派生因子。切换股票池时，页面会同步更新股票池成员过滤条件。
4. DSL 至少需要产生一个可分析的派生列；因子列由页面根据 DSL 自动生成，不需要单独填写。
5. 点击“执行分析”，右侧显示运行日志；完成后自动读取报告。

股票池和常用研究参数由普通面板生成完整请求，三个点菜单中的“展示参数”仍可查看并编辑最终 JSON。

## 阅读报告

结果区顶部按 `factor_columns` 生成因子标签。当前普通面板通常只产生一个因子，高级请求可以同时包含多个因子。

日期范围条会同时作用于当前因子的全部报告区域：

- **IC 分析：** 在 RankIC 与 IC 之间切换，查看均值、标准差、IR、正值占比和累计曲线；
- **收益分析：** 按收益列顺序切换，查看多空收益与累计收益；
- **分组分析：** 查看分组平均收益、显著性和各组净值曲线；
- **衰减分析：** 比较不同收益期限下的 IC 与 RankIC 均值。

当收益列覆盖多个交易期且观测重叠时，页面会提示哪些累计或年化指标不适合计算。

指标名称旁的问号可查看计算与年化口径。ICIR 和 Rank ICIR 是 IC 均值除以 IC 样本标准差，页面展示
的是**未年化**值；收益列周期、重叠观测与自相关都会影响换算，不能固定乘 `√252`。只有 1 日非重叠
多空收益会直接计算累计收益、按 252 个交易日折算的年化收益、年化波动和年化 Sharpe；多期收益只
保留原始周期的均值、标准差、IC 和分组统计。

## 保存和继续研究

- 新项目从 `v1 · 未保存` 开始；你可以反复执行并覆盖当前草稿。
- 工作流成功后点击“保存”，填写版本备注并固定本次参数与结果。
- 保存后会创建下一个未保存草稿；历史版本是只读的。
- 查看历史版本时点击“基于此版本研究”，可以把它复制回草稿继续修改。
- 版本导航的三个点可进行版本对比、重命名当前版本和删除当前版本。

项目首页的“对比研究”用于选择不同项目/版本横向比较；详情页版本导航中的“版本对比”用于比较同一项目内的版本。

## 队列和因子优选

详情页右下三个点菜单还提供：

- **提交到队列：** 保存当前参数快照和备注，但暂不运行；待执行项目保存在当前浏览器。
- **队列：** 编辑待执行任务的备注或完整 JSON，点击“批量执行”后并发提交；每个成功任务自动生成递增版本。
- **因子优选报告：** 至少有两个已保存版本时可用，用于比较历史因子研究结果。

队列中的待执行内容属于本地浏览器数据；更换浏览器或清理站点数据前应先批量执行需要保留的任务。
