# 工作流、状态与日志

工作流页用于统一查看 Query、Factor、Backtest、敏感性分析、参数调优和增量更新。它按 Workspace 分组，而不是把每次执行完全平铺。

## 查看当前运行

进入[工作流](/workflows)后可以按应用和状态筛选。当前仍在运行的记录每 5 秒自动更新，也可以手动点击“刷新”。

主表每行展示：

- 对应应用与项目名称，点击应用胶囊可回到自己拥有的项目详情；
- Workspace ID 和工作流定义 ID；
- 当前 Attempt 的状态和 ID；
- 当前 Task 胶囊、开始时间、耗时及总运行次数；
- 查看详情与终止工作流操作。

点击行首箭头展开历史运行。每个 Attempt 都保留自己的输入、状态、错误和生命周期事件；打开“运行详情”可以查看完整请求体和相关 ID。

## 状态怎么理解

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| QUEUED / CREATED / SUBMITTING / SUBMITTED | 正在创建或提交 | 等待页面自动更新 |
| RUNNING_EXECUTION | DolphinScheduler 正在执行 | 点击 Task 胶囊中的日志按钮 |
| RESULT_PENDING | 调度已成功，后端正在确认输出文件 | 继续等待，短暂存储异常会自动重试 |
| SUCCESS | 调度与结果校验均成功 | 回到应用详情读取结果或保存版本 |
| FAILURE | 执行失败 | 查看失败 Task 的完整日志 |
| RESULT_FAILED | 调度成功但必需结果缺失、为空或损坏 | 查看日志确认产出步骤，不要直接保存版本 |
| AUTO_SAVE_PENDING | 队列任务正在生成版本 | 等待自动保存完成 |
| AUTO_SAVE_FAILED | 任务成功但自动保存版本失败 | 查看 Attempt 错误并重试相关操作 |
| STOP / KILL | 已终止 | 修改参数后重新执行 |

## 查看日志

- 项目执行期间，详情页右侧直接显示日志组件。
- 三个点菜单中的“Task 日志”会打开通用日志弹窗，可先选择 Task。
- 工作流页的 Task 胶囊带有日志按钮，可直接打开该 Task。
- 日志按字节分页读取，适合大日志；切换分页不会截断整个日志文件。
- DolphinDB 代码中的输出已经重定向到 Task 日志，可以打印阶段进度和用于调试的少量上下文。

日志应服务于定位阶段、输入范围和异常，不要在逐行行情循环中打印大表，否则会显著增加日志读取成本。

## 终止与重试

运行中的项目执行按钮会切换为红色终止操作，工作流页也提供同一能力。终止只针对当前 Workflow Instance，不会删除项目、历史 Attempt 或已经保存的版本。

如果任务失败，先记录 Attempt ID 和失败 Task，再查看完整日志。修正参数或代码后回到应用详情重新执行；新运行会创建新的 Attempt，旧记录仍可用于比较。
